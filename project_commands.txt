UR12e winding project: rebuild and launch
========================================

Workspace:
  /home/piero/ur12e_ws


One-time setup on a new laptop
------------------------------

source /opt/ros/jazzy/setup.bash
sudo apt update
sudo apt install ros-jazzy-trac-ik-kinematics-plugin


Terminal 1: rebuild the package
-------------------------------

cd /home/piero/ur12e_ws
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select ur12e_motion dbar_tensegrity
source install/setup.bash


Terminal 1: launch the UR12e simulation with TRAC-IK
---------------------------------------------------

ros2 launch ur_simulation_gz ur_sim_moveit.launch.py ur_type:=ur12e moveit_launch_file:=/home/piero/ur12e_ws/install/ur12e_motion/share/ur12e_motion/launch/ur_trac_ik_moveit.launch.py

Leave this terminal running.


Terminal 2: run the IK client
-----------------------------

cd /home/piero/ur12e_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash
ros2 run ur12e_motion ik_client


Optional: verify that MoveIt is using TRAC-IK
---------------------------------------------

Run this in another sourced terminal while the simulation is running:

ros2 param get /move_group robot_description_kinematics.ur_manipulator.kinematics_solver

Expected output:
  String value is: trac_ik_kinematics_plugin/TRAC_IKKinematicsPlugin


Stopping the programs
---------------------

Press Ctrl+C in the IK client terminal, then press Ctrl+C in the simulation
terminal.
